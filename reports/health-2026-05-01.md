## Detailed findings

### H-01 — 🟠 ESLint 9 flat config has empty rules; lint gate is a no-op

- **Where:** [eslint.config.cjs](../eslint.config.cjs), shadowed by legacy [.eslintrc.cjs](../.eslintrc.cjs).
- **Evidence:** `npm run lint` exits clean with no output. The flat config exposes `rules: {}` for both TS and Svelte blocks. The legacy file extends `eslint:recommended`, `plugin:@typescript-eslint/recommended`, `plugin:svelte/recommended`, `prettier`, but ESLint 9 ignores it whenever a flat config exists. Reproduced: `npx --yes eslint . -c .eslintrc.cjs` errors with `A config object is using the "root" key, which is not supported in flat config system` — i.e. ESLint 9 only speaks flat.
- **Why it matters:** The CI gate at [.github/workflows/ci-gates.yml:42](../.github/workflows/ci-gates.yml#L42) currently asserts "lint passed" while checking nothing.
- **Fix:**
  ```js
  // eslint.config.cjs
  const tseslint = require('@typescript-eslint/eslint-plugin');
  const tsparser = require('@typescript-eslint/parser');
  const svelte = require('eslint-plugin-svelte');
  const svelteParser = require('svelte-eslint-parser');
  const prettier = require('eslint-config-prettier');

  module.exports = [
    { ignores: ['node_modules/**', '.svelte-kit/**', '.wrangler/**', 'public/**', 'build/**', 'coverage/**'] },
    {
      files: ['**/*.{js,ts}'],
      languageOptions: { parser: tsparser, ecmaVersion: 2024, sourceType: 'module' },
      plugins: { '@typescript-eslint': tseslint },
      rules: { ...tseslint.configs.recommended.rules },
    },
    {
      files: ['**/*.svelte'],
      languageOptions: { parser: svelteParser, parserOptions: { parser: tsparser } },
      plugins: { svelte },
      rules: { ...svelte.configs['flat/recommended'][0].rules },
    },
    prettier,
  ];
  ```
  Then delete `.eslintrc.cjs`. Expect a one-time backlog; triage with `--max-warnings=N` set high, then ratchet down.

### H-02 — 🟠 No automated unit tests; coverage cannot be measured

- **Where:** Repo-wide. [package.json](../package.json) has `test:smoke`/`test:integration` scripts but no unit-test runner.
- **Evidence:** `find . -name 'vitest.config.*' -o -name 'jest.config.*'` → empty. `coverage/` does not exist.
- **Why it matters:** The 1,483-line [src/lib/server/content/store.ts](../src/lib/server/content/store.ts) and the auth flow in [src/lib/server/auth/editor.ts](../src/lib/server/auth/editor.ts) are validated only by booting `wrangler dev` and curling — fine for happy paths, weak for branch coverage and slow as a feedback loop. The integration jobs in CI have a 35-minute timeout (H-08).
- **Fix:** Adopt Vitest. Three starter test files cover the highest-risk pure code:
  ```bash
  npm install -D vitest @vitest/coverage-v8
  ```
  ```js
  // vitest.config.ts
  import { defineConfig } from 'vitest/config';
  export default defineConfig({
    test: { include: ['src/**/*.{test,spec}.{ts,svelte}'], coverage: { reporter: ['text','html'] } },
  });
  ```
  Targets in priority order: `store.ts` Zod schemas (`projectCreateSchema`, `goalCreateSchema`, `projectPatchSchema`); `hooks.server.ts` `consumeWriteLimit`/`parsePositiveInt`; `http.ts` `parseIncludeArchived`/`parseLimit`/`toHttpError`. Add `npm test` to `ci:gate`.

### H-03 — 🟠 Dependency freshness: 4 majors behind, 17 advisories outstanding

- **Evidence:** `npm outdated --json` shows `@sveltejs/vite-plugin-svelte` 6→7, `eslint` 9→10, `typescript` 5→6, `vite` 7→8 plus 13 minor/patch trailing. `npm audit` reports 1 low / 7 moderate / **9 high** / 0 critical. ### H-05 — 🟡 `goal` and `project` `+server.ts` handlers are 40–48% duplicated

- **Where:** [src/routes/api/projects/+server.ts](../src/routes/api/projects/+server.ts) ↔ [src/routes/api/goals/+server.ts](../src/routes/api/goals/+server.ts), and the `[id]/+server.ts` pair.
- **Evidence:** jscpd reports clones of 12, 11, and 14 lines across these four files (jscpd JSON, lines 199-321). Each `[id]/+server.ts` is ~45% duplicated of its sibling.
- **Why it matters:** Any change to error mapping, auth, or response shape has to be made in two places forever. Guarantees future skew.
- **Fix:** Add a small generic helper in [src/lib/server/content/](../src/lib/server/content/):
  ```ts
  // crud-handlers.ts
  type Store<T> = {
    list(event: RequestEvent, opts: { includeArchived: boolean }): Promise<T[]>;
    get(event: RequestEvent, id: string, opts: { includeArchived: boolean }): Promise<T>;
    create(event: RequestEvent, payload: unknown, actor: string): Promise<T>;
    update(event: RequestEvent, id: string, payload: unknown, actor: string): Promise<T>;
    archive(event: RequestEvent, id: string, actor: string): Promise<T>;
  };
  export function makeCollectionHandlers<T>(store: Store<T>) { /* GET, POST */ }
  ```
